## วิธีใช้งาน

### เลือกระดับและกรองคำ
- กดการ์ดระดับ **ทั้งหมด / A1 / A2 / B1 / B2 / C1** ด้านบน แถบสีเขียวใต้แต่ละระดับคือความคืบหน้า
- **ช่องค้นหา:** พิมพ์คำภาษาอังกฤษหรือคำแปลไทยก็ได้
- **ชนิดคำ:** กรองเฉพาะคำนาม คำกริยา คำคุณศัพท์ ฯลฯ
- **สถานะ:** เลือก "ยังไม่จำ" เพื่อทบทวนเฉพาะคำที่ยังจำไม่ได้
- **เสียง UK / US:** เลือกสำเนียงเสียงอ่าน

### โหมดตาราง
- ดูคำศัพท์ทีละ 100 คำต่อหน้า พร้อมคำอ่าน คำแปล และตัวอย่างประโยค
- กด 🔊 เพื่อฟังเสียงคำศัพท์หรือประโยค
- ติ๊กช่อง **จำแล้ว** เมื่อจำคำนั้นได้
- บนมือถือจะซ่อนคอลัมน์ IPA และตัวอย่างประโยคเพื่อให้อ่านง่าย คำอ่านไทยจะแสดงใต้คำศัพท์แทน

### โหมดแฟลชการ์ด
- ด้านหน้าการ์ดแสดงคำศัพท์และ IPA **แตะการ์ด** เพื่อพลิกดูคำอ่าน คำแปล และตัวอย่างประโยค
- กด **จำได้แล้ว ✓** หรือ **ยังไม่จำ** ระบบจะบันทึกสถานะและไปการ์ดถัดไป
- กด **สุ่มลำดับ** เพื่อสลับลำดับการ์ด
- เคล็ดลับ: ตั้งสถานะเป็น "ยังไม่จำ" แล้วเล่นแฟลชการ์ด จะได้ทบทวนเฉพาะคำที่ยังไม่แม่น

### โหมดแบบทดสอบ
- ทดสอบแบบ 4 ตัวเลือก ระบบจะสุ่มถามทั้งแบบ อังกฤษ → ไทย และ ไทย → อังกฤษ
- ตอบถูก คำนั้นจะถูกทำเครื่องหมายว่าจำได้แล้ว ตอบผิดจะกลับไปเป็น "ยังไม่จำ"
- หลังตอบจะแสดงคำอ่านและตัวอย่างประโยค กด **ข้อต่อไป** เพื่อทำข้อถัดไป

### คีย์ลัด (บนคอมพิวเตอร์)
| ปุ่ม | แฟลชการ์ด | แบบทดสอบ |
|---|---|---|

| ← / → | การ์ดก่อนหน้า / ถัดไป | – |
| 1 | ยังไม่จำ | เลือกตัวเลือก 1 |
| 2 | จำได้แล้ว | เลือกตัวเลือก 2 |
| 3 / 4 | – | เลือกตัวเลือก 3 / 4 |

## ความคืบหน้าและการสำรองข้อมูล

ความคืบหน้าจะ **บันทึกไว้ในเบราว์เซอร์ของแต่ละเครื่อง** ไม่ได้อัปโหลดไปไหน ความคืบหน้าในคอมกับมือถือจึงแยกกัน

**ย้ายหรือสำรองความคืบหน้า** (ปุ่มอยู่ท้ายหน้า)
1. เครื่องเดิม: กด **สำรองความคืบหน้า** จะได้ไฟล์ `oxford5000-progress-วันที่.json`
2. ส่งไฟล์ไปยังอีกเครื่อง (เช่น ทาง LINE, อีเมล หรือ iCloud/Google Drive)
3. เครื่องใหม่: กด **นำเข้าความคืบหน้า** แล้วเลือกไฟล์นั้น ข้อมูลจะรวมกับของเดิมโดยไม่ลบของเดิม

> **ผู้ใช้ iPhone:** Safari อาจลบข้อมูลของเว็บที่ไม่ได้เปิดนานประมาณ 7 วัน ควรเปิดแอปจากไอคอนบนหน้าจอโฮม และกดสำรองความคืบหน้าเก็บไว้เป็นระยะ

ปุ่ม **ล้างความคืบหน้า** จะลบสถานะ "จำได้แล้ว" ทั้งหมดในเครื่องนั้น (ยกเลิกไม่ได้)
